# Open Questions

This document collects questions that the project does not yet know how to answer.

They should remain visible rather than being hidden behind premature design decisions.

## Evidence

* What should count as evidence?
* How should different evidence types be weighted?
* Can evidence reliability be estimated?
* How should old evidence decay over time?
* How should context affect interpretation?

## Human judgment

* How should expert credibility be represented?
* How should evaluator disagreement be handled?
* Can expert bias be detected?
* Should some judgments require multiple evaluators?

## Learner modeling

* Which learner attributes are appropriate to model?
* Which should deliberately not be modeled?
* How should changing interests be represented?
* How should learning potential differ from current performance?

## Career reasoning

* What level of career specificity is appropriate?
* Should the system recommend occupations, career families, environments, or experiments?
* How should labor-market information affect recommendations?
* How should lifestyle preferences be incorporated?

## Exploration

* How can the system discover abilities that have never been tested?
* How much deliberate exploration is appropriate?
* How can recommendation feedback loops be prevented?

## Equity

* How should the system respond when a learner lacks access to experts, equipment, internships, or educational opportunities?
* Can simulated experiences provide useful evidence?
* How should structural barriers be represented?

## Longitudinal validity

* How long would meaningful evaluation require?
* What outcomes should matter?
* Career satisfaction?
* Learning?
* Income?
* Mobility?
* Well-being?
* Social contribution?

## Architecture

* Should the system use a graph representation?
* Which information should be structured?
* Which information should remain qualitative?
* What should AI infer automatically?
* What should always require human confirmation?

## Fundamental question

What would count as convincing evidence that this system actually helps learners make better decisions?
