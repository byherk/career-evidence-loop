# Examples

This directory contains simplified examples used to test and explain the Career Evidence Loop framework.

The examples are conceptual.

Unless explicitly stated otherwise, they should be treated as fictional and should not contain identifiable learner information.

Examples should help explore questions such as:

* What counts as evidence?
* What is merely an inference?
* How should uncertainty be represented?
* What makes a career hypothesis defensible?
* What evidence is missing?
* What experiment should happen next?
* Where should human expertise enter the process?

Current examples:

* `learner-journey.md`
* `career-hypothesis.md`
* `expert-feedback.md`
* `evidence-loop.md`
