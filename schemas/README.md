# Schemas

This directory is reserved for future structured representations used by Career Evidence Loop.

No schema should be treated as stable at this stage.

The conceptual model should mature before implementation decisions become difficult to reverse.

## Possible future schemas

* `learner-profile.schema.json`
* `observation.schema.json`
* `evidence-record.schema.json`
* `expert-feedback.schema.json`
* `career-hypothesis.schema.json`
* `career-experiment.schema.json`

## Important design questions

Important design questions include:

* evidence provenance;
* uncertainty;
* contradictory evidence;
* missing evidence;
* learner consent;
* evaluator identity and role;
* temporal change;
* hypothesis revision history.

Schemas should follow the research model rather than prematurely defining it.
